## What was built

| Piece | Where |
|---|---|
| The developer menu: L3 + R3 anywhere; Settings (upstream's registry menu), Trainer, Free camera, Performance overlay, Frame-time recording, Diagnostics on screen, Close; D-pad / stick to move, A chooses, B closes (the Nintendo layout, at the user's request), the touch screen too | `src/devmenu/dev_menu.cpp`, `.h` |
| The chord filter: every L3 / R3 press waits 100 ms (`VCS_NX_CHORD_MS`, 20-500) for the other; a chord toggles the menu and both buttons stay from the game until let go; a lone press is handed on held, or as a pulse of at least 2 pumps and 60 ms for a tap; every event logged (`[chord]`) | `src/devmenu/chord.cpp`, `.h`; `src/platform/platform_switch_sdl2.cpp` `filterSticks` |
| Touch: switch-sdl2 2.28 delivered no touch at all on hardware (no mouse and no `SDL_FINGER*` event), so the panel is read from HID (`hidGetTouchScreenStates`) each pump and fed to Dear ImGui as a touch-screen mouse, scaled from the panel's 1280x720 to Dear ImGui's display (the output size); mouse events are scaled from the 1920x1080 window | `src/platform/platform_switch_sdl2.cpp` `pollTouch`, `toUiCoordinates` |
| Settings: the Keyboard page, the desktop window and the background behaviour hidden; Advanced > Diagnostics gets "Switch diagnostics" and "Frame-time recording"; the boot log lists every setting not at its default | `src/devmenu/dev_menu.cpp` `registerSettings`, `src/core/core.cpp` `logSettings` |
| Root patch 0012: the host UI hook drawn first in upstream's UI callback (it blocks the game's input like the menus); the desktop Back + Start / RB / LB chords switchable (off on the Switch: Back is the game's Select); the trainer opened / closed from another menu; the menus' A / B following `io.ConfigNavSwapGamepadButtons`; `ps2perf::setRecording`; `settings::setHidden` and no empty tabs; vcs.ini values must be whole decimal integers (atoi took `abc` as 0); `vcs::trainer::usedCount` | `patches/upstream/0012-switch-dev-menu-seams.patch` |
| Trainer use is not silent: the log says so and `userdata/<profile>/trainer-used.txt` is written at the first use of a run | `src/devmenu/dev_menu.cpp` `noteTrainerUse` |
| `VCS_NX_OUTPUT=1080` (a run setting): the docked 1920x1080 output in handheld, scaled down by the panel, to check the 1080p layout without a dock | `src/switch/output.c` |
| Host tests: the chord filter at 5 / 16 / 43 / 84 ms pumps; the settings registry against damaged files, relaunch, reset, hidden rows | `tests/core/chord_tests.cpp`, `tests/core/settings_tests.cpp`, `tools/run_core_host_tests.py` |
| Hardware session tool (frame-time CSVs read back, chord / menu / touch / settings log summary, the 512-command limit checked before a run is sent) and run files | `tools/switch_m08_session.py`, `tests/switch/m08-*.cfg`, `tests/switch/m08-damaged.ini` |
